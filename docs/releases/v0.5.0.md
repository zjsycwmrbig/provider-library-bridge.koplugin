# v0.5.0 — 文件夹识别与真实阅读进度

本版解决占位书移入文件夹后重复创建，以及书架进度显示占位 HTML 页数的问题。

## 文件夹识别

- 同步开始时递归扫描目标书库中的 HTML 占位书。
- 通过 sidecar 中的 Provider 与书号识别书籍，不依赖旧的固定路径。
- 占位书被移动到“已读”等文件夹后，继续更新原文件，不再在根目录生成副本。
- 同步状态和历史记录会迁移到重新发现后的路径。
- 同一本书存在多份副本时，优先最近打开或修改的一份，并保留其他副本以便人工确认。

## 真实阅读进度

- 把来源进度转换为 KOReader 原生 `percent_finished`，书架和 SimpleUI 直接显示该值。
- 不再依赖占位 HTML 的页数，因此不需要伪造 100 页。
- 来源进度达到 99.5% 时同步标记为完成。
- 打开占位书并切换来源文档时，保存钩子会保留来源进度，避免短 HTML 的页进度覆盖。
- 番茄打开前刷新进度后，也会立即更新占位书进度。

## 安装

下载 `provider-library-bridge.koplugin-v0.5.0.zip`，替换
`koreader/plugins/provider-library-bridge.koplugin/` 后重启 KOReader。

重启后执行一次“立即同步”。已有根目录副本不会再生成，移动后的占位书会被重新关联。
