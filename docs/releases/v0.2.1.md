# v0.2.1 — 首个公开预览版

将番茄小说、微信读书插件中已有本地章节缓存的书，桥接到 KOReader 本地书架。

## 功能

- 平铺的 HTML 占位书，点击后交给来源插件打开。
- 手动同步及 KOReader 运行期间的定时同步。
- 优先复用官方封面；失败时使用三款 SVG + 楷体默认封面并缓存成 PNG。
- 来源标签独立绘制，不写进封面或书名。
- 详情卡片展示进度、章节、上次打开、缓存大小及同步时间。
- 同步与打开进度通知在屏幕底部显示。

## 本版修复

- 统一 SVG 模板文件名和查找路径。
- 按原始字节写入 HTML、SVG 和下载图片，去除误加的 Lua 文件头。
- 内置霞鹜文楷 Lite，避免设备缺字体；输出封面为 600 × 800 PNG。
- 离线复用缓存的官方封面。

## 验证与限制

已在 Kindle / KOReader v2026.07.1 上完成安装校验、LuaJIT 测试及三款封面
的真实渲染引擎验证。完整书架 UI、来源角标、底部通知和点击跳转仍需进一步验收。
默认书库路径为 /mnt/us/Books；其他平台尚未验证。

来源插件接口可能变化。本插件只处理已有章节缓存的书，不同步完整云端书架，
不打包来源插件、账号或小说正文。

## 安装

下载本 Release 的 provider-library-bridge.koplugin-v0.2.1.zip，
将其中同名 .koplugin 目录放入 koreader/plugins/，重启 KOReader，
在“工具 → 在线书库本地书架 → 立即同步”更新现有占位书。

升级前退出 KOReader，新版替换旧插件目录；保留设置和来源插件的章节缓存。
