# v0.6.0 — Suwayomi Library 适配

新增 Suwayomi Provider，将 Suwayomi Library 的漫画同步为 KOReader 本地书架中的
占位书。

## 同步范围

- 默认的“已知书架”读取 `suwayomi.lua` 中保存的 Library 快照。
- 同时合并章节缓存、下载账本和阅读返回上下文。
- 没有本地章节的 Library 漫画也会生成占位书。
- “仅已缓存”只保留至少有一个现存本地 CBZ 的漫画。

## 书架信息

- 每本漫画只生成一个占位书，不会把每个章节都铺到书架。
- 显示来源标签 `Suwayomi`。
- 已下载章节数和总章节数来自本地下载账本与章节缓存。
- 阅读进度按已读章节或 Library 未读数量计算。
- 上次阅读章节来自本地阅读上下文。
- 本地 CBZ 所在目录会映射到占位书，章节历史归并到同一本漫画。
- 可复用 Suwayomi 本地缩略图，或在联网同步时向服务器获取封面；失败时使用默认封面。

## 打开流程

点击占位书后调用 Suwayomi 插件的 `showChaptersForManga()`，进入对应漫画的章节
列表。章节下载、阅读、标记已读和来源同步继续由 Suwayomi 插件负责。

## 安装

替换 `koreader/plugins/provider-library-bridge.koplugin/` 后重启 KOReader，执行一次
“立即同步”。Suwayomi 插件需要保持安装和启用。
