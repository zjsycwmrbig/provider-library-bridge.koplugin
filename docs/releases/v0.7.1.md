# v0.7.1 — Suwayomi 首个未读定位

## 改进

- 从书架或历史记录打开 Suwayomi 占位书时，章节列表会定位到第一个未读章节，
  不再固定显示第一页。
- 打开前会重新读取 Suwayomi 插件保存的 Library 快照和章节缓存，因此阅读状态在
  最近一次同步后发生变化时，也会使用较新的未读位置。
- 优先采用 Suwayomi Library 快照提供的 `first_unread_chapter`；缺少该字段时，
  按 `source_order` 从章节缓存中推导。
- 全部章节已读时不强制选择章节，仍显示正常的章节列表。

## 同步范围

本版本不改变同步来源。桥接插件仍只读取 Suwayomi 插件保存的本地
`library_cache`、`chapter_cache`、`chapter_ledger` 和阅读返回上下文，并更新
`/mnt/us/Books` 中由本插件创建的占位书。来源书架变化需要先刷新 Suwayomi
插件；桥接同步本身不会额外请求服务器书架。
