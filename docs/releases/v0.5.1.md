# v0.5.1 — 修复番茄阅读进度

修复番茄占位书进度缺失、旧进度不更新，以及详情页打开时只获取章节位置却没有
重新计算百分比的问题。

## 修复

- 联网同步时调用番茄插件的云端阅读进度接口，每次请求覆盖整批书架记录。
- 优先使用云端 `read_progress`，它比“已读章数 / 总章数”更接近实际进度。
- 云端不可用时回退到本地 `shelf_cache.lua`。
- 番茄详情页打开前，云端返回的 `read_progress` 会同步回占位书进度。
- `percent_finished` 缺失或与 marker 不一致时，不再误判为 `unchanged`。
- marker schema 升级到 3，首次同步会迁移旧占位书。
- marker 记录 `progress_source = cloud` 或 `shelf`，便于确认进度来源。

## 已知限制

- 番茄服务端给的是整书阅读进度，仍以章节为主要刻度；没有精细到正文页面像素。
- 未联网或 Cookie 失效时只能使用来源插件最近一次保存的本地书架快照。

## 安装

替换 `koreader/plugins/provider-library-bridge.koplugin/` 后重启 KOReader，
在联网状态执行一次“立即同步”。
