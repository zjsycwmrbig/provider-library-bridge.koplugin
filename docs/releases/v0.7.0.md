# v0.7.0 — 来源插件多选与 Suwayomi 封面

新增同步来源选择和插件扫描，并修复 Suwayomi 本地封面缓存读取。

## 同步来源

- 设置中新增“同步来源”二级菜单。
- 每个 Provider 以复选项显示。
- 已安装并启用的来源插件可以单独启用或停用。
- 缺失或停用的来源插件显示“插件未启用”，不能选择。
- “重新扫描来源插件”会重新加载 Provider 列表并刷新可用状态。
- 新出现的 Provider 默认启用；停用状态会保存在设置中。
- 停用某个来源不会删除已经生成的占位书，重新同步后也不会更新该来源。

## Suwayomi 封面

- 同时查找 Suwayomi 的 `poster` 320×480 和 `manga_cover` 64×96 缩略图缓存。
- 解码插件的 `SWTHUMB1` 缓存并导出为封面 PNG。
- 本地缓存缺失但服务器可用时，继续尝试从 Suwayomi 下载封面。
- 只有全部来源都失败时才使用通用封面。

Suwayomi 的标题来自其 Library/章节快照中的原始标题。为保留书名含义，Suwayomi
的显示标题不再删除冒号等标点；文件名仍单独过滤文件系统不允许的字符。来源没有保存
中文译名时，无法从本地缓存推断译名。
