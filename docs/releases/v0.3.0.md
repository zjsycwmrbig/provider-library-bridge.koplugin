# v0.3.0 — 同步范围设置

新增可配置的同步范围，默认同步来源插件已知书架中的全部书，不论是否已经缓存。

## 新功能

- 设置 → 同步范围：
  - 已知书架（含未缓存），默认；
  - 仅已缓存，沿用此前行为。
- 番茄合并 `shelf_cache.lua` 书架快照和已有缓存目录。
- 微信读书优先读取 `library_db` 书架快照，并合并本地缓存记录。
- 未缓存书也生成占位书、来源标签、进度和封面；官方封面不可用时使用默认封面。
- 点击未缓存书：
  - 番茄联网打开目录；
  - 微信读书先打开书籍详情，供下载或开始阅读。
- 新增番茄和微信读书 Provider 的范围回归测试。

## 注意

同步只读取来源插件已经保存的本地书架快照，不会为了刷新书目额外请求网络。
请先在来源插件中打开或刷新一次书架。

切换为“仅已缓存”不会自动删除之前按“已知书架”创建的占位书。如需立即收回，
先清除全部占位书，再按新范围同步。

## 安装

下载 `provider-library-bridge.koplugin-v0.3.0.zip`，将其中同名 `.koplugin`
目录放入 `koreader/plugins/`，重启 KOReader。随后在
“工具 → 在线书库本地书架”检查同步范围并执行立即同步。
