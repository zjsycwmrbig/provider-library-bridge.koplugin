# v0.4.0 — 占位书统一历史记录

让番茄小说和微信读书的占位书成为 KOReader 与 SimpleUI 历史中的唯一记录。

## 新功能

- 不再在打开占位书后从 `ReadHistory` 删除它。
- 番茄和微信读书实际缓存章节会被映射回对应占位书。
- 同一本书的多个章节历史会合并，保留最新阅读时间。
- 历史条目仍指向 `/mnt/us/Books/` 中的占位书，点击后由桥接插件继续打开来源内容。
- 书改名时更新来源路径映射；清除占位书时同步移除映射。
- 新增历史映射回归测试。

## 注意

这是一次历史语义变更：来源插件不再为每个章节产生独立历史条目，而是统一显示
一本占位书。历史上已有的来源章节条目会在同步后合并。

安装后需要重启 KOReader，并执行一次“立即同步”，以建立来源缓存路径到占位书的
映射并整理已有历史。

## 安装

下载 `provider-library-bridge.koplugin-v0.4.0.zip`，替换
`koreader/plugins/provider-library-bridge.koplugin/` 后重启 KOReader。
