# 通用 SVG 封面

这些矢量封面用于在线书库占位书在获取不到来源封面时显示。书名和作者由
插件按当前书籍生成。

## 文件

- `02-eclipse.svg`：暗日，低密度同心几何
- `03-current.svg`：流线，暗灰底叠加深浅曲线
- `05-lattice.svg`：墨格，深底细格与内框

三张封面均为 900 × 1200、灰度、2:3 比例。所有图形和文字都位于 SVG
内部，不依赖任何位图素材。

## 显示原则

- 正文使用文楷或系统楷体，标题和作者均可动态替换；
- 只用灰度、粗轮廓和中等细节，避免墨水屏缩略图出现灰雾；
- 来源标签不进入封面，由书架列表或网格 badge 显示。
