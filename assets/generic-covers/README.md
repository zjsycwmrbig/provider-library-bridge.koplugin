# 通用封面背景

这些图片用于在线书库占位书在获取不到来源封面时显示。它们只提供背景，
书名和作者由插件按当前书籍生成。

## 文件

- `light.jpg`：阳光穿过百叶窗形成的光影
- `cloud.jpg`：云层与天空
- `lattice.jpg`：中式园林八角窗格

三张图片均已转换为 900 × 1200、灰度、2:3 的电子墨水屏背景，并降低了亮度
以便叠加浅色书名。
